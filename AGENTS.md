* The following is important when you are working on a task:
  * Always conduct a code review after code is ready and tests passed.
  * Always wait for a clear commit approval if not stated otherwise.
  * When a remote GitHub workflow is triggered by push, merge or a raised PR, wait for it to finish, before making a decision on how to proceed with further actions.
  * Always create a GitHub PR when merging any branch to the main.
  * After a successful merge to the main, assure the merge has been done correctly and then ask whether the source branch should be deleted.
